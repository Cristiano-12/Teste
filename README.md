# Northframe Revenue Ops

Northframe Revenue Ops is a polished B2B SaaS analytics sample built with Next.js, TypeScript, Tailwind CSS, Recharts and Lucide icons.

It demonstrates dense product UX for revenue operations and customer intelligence workflows:

- Overview dashboard with KPI hierarchy, revenue chart, health distribution and activity feed
- Accounts table with search, filters, sorting, selection, pagination and responsive mobile account items
- Account details drawer with health, usage, recent activity, risk signals and task feedback
- Analytics page with revenue growth, revenue by plan, cohort retention and product adoption

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality Checks

```bash
npm run lint
npm run typecheck
npm run build
```

The app is static-data only and does not require API keys or a backend.

## Deploy

This project is ready for Vercel. Import the repository, keep the default Next.js settings, and deploy.
